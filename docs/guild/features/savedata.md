# 游戏存档备份

## 存档备份相关设置

1. 打开游戏详情页的`存档`标签。
2. 选择游戏的存档文件夹或单个存档文件。
3. 设置最大备份数量，按需开启`自动备份`，点击`保存备份设置`。
4. 点击`创建备份`进行手动备份，结果会出现在`备份历史`中。

**存档路径**是指游戏本身的存档所在的文件夹或者文件，常见文件夹名有 `savedata`、`save`、`userdata`备份的存放位置由全局的游戏存档备份路径决定。

开启自动备份后，游戏结束且成功记录本次游玩时会备份存档。有效计时时长不足一分钟时不会触发，详见[游玩记录与统计](statistics.md)。

备份保存为 `.7z` 文件，默认位于：

- 安装版：`%AppData%\com.reinamanager.dev\backups`
- 便携版：`resources\backups`

可通过`打开备份文件夹`查看文件。需要修改备份目标目录时，可以前往`设置 → 路径与备份 → 打开路径设置`，修改`游戏存档备份路径`并按提示迁移已有备份。

## 恢复与删除

在`备份历史`中点击恢复按钮，将备份恢复到已保存的存档路径。**恢复会覆盖当前存档，建议先创建一次备份。**

删除按钮会删除备份文件和记录。文件缺失或无法删除时，可按提示选择`只清除记录`；这不会删除仍存在的文件。
