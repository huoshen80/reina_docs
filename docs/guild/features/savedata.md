# 游戏存档备份

## 存档备份相关设置

在游戏详情页的存档 Tab 中，你可以设置**存档路径**、**最大备份数量**、**是否自动备份**

关于自动备份，该功能开启后会在你每次正常结束游戏（时长 > 1min）后自动备份存档

存档备份会将存档压缩成 7z，然后默认放在`%AppData%\com.reinamanager.dev\backups`（安装版）或者`resources\backups`（便携版），你可以在设置-路径与备份-打开路径设置-游戏存档备份路径中修改

::: warning
  **存档路径**是指游戏本身的存档所在的文件夹，通常以 `savedata` `save` `userdata` 等命名
:::

## 备份的删除与恢复

在备份历史列表中，你可以选择删除某个备份或者恢复某个备份
