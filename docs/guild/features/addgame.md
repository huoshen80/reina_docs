# 添加游戏

支持手动添加、拖拽添加、批量导入和云端收藏导入。

## 单个添加

1. 点击工具栏的`添加游戏`，需要关联本地游戏时，点击`选择启动文件`；也可以先用游戏名称搜索条目，再到[启动设置](editgame.md#启动设置)关联启动文件。
2. 选择添加模式，推荐使用 `Mixed`。
3. 检查游戏名称，确认无误后点击`确认`开始搜索。选择启动文件后，名称会从所在文件夹自动提取，也可以手动修改。
4. 检查各数据源的匹配结果，再确认添加。

![单个添加：可选择启动文件，也可直接输入名称并选择添加模式](/images/addgame-single_20261002.png)

Mixed 搜索会显示各来源的候选条目。请核对名称、ID 和发行日期，勾选需要保留的来源，再点击`确认`。

![Mixed 确认弹窗：核对各来源的候选条目](/images/addgame-confirm_20261002.png)

匹配有误时，点击该来源的`查看更多`，选择正确条目。单源名称搜索也会显示游戏选择列表。

![候选列表：区分同名游戏、续作和不同版本](/images/addgame-results_20261002.png)

### 添加模式

Reina 添加游戏有多种模式，默认使用游戏名称进行 `Mixed` 搜索，此外还支持`单数据源`的游戏名称或者 ID 搜索以及`自定义`游戏

Mixed 使用的来源可在`设置 → 数据源 → Mixed 搜索源`中配置，启用数量为 2–4 个。未启用的来源不会参与 Mixed 搜索。

#### 自定义

想导入数据源可能没有的游戏时，可以选择`自定义`模式，填写名称完成添加，再到[游戏详情页编辑](editgame.md)补充封面、简介等资料。

#### 单源 ID 搜索

你可以在对应源的输入框中填入游戏 ID 进行准确搜索

游戏 ID 通常位于条目网址中。例如打开 [VNDB](https://vndb.org/)，搜索游戏并进入条目页面，即可在网址栏中找到 ID。
![游戏ID位置](https://img0.huoshen80.top/i/2026/01/02/69579ad5ba25c.png)

## 拖拽文件夹或者启动文件

- 直接将游戏文件夹或者游戏启动文件拖拽到 Reina 内，松开鼠标后会自动进入添加流程

- 拖动多个游戏文件夹或者启动文件时，Reina 会自动进入批量导入流程

- 批量导入模式下再次拖拽游戏文件夹或者启动文件会被视为批量导入的补充操作

## 批量导入

1. 在添加游戏弹窗中切换到`批量导入`，选择包含游戏文件夹的根目录。
2. 在`高级设置`中选择扫描模式，按需调整扫描深度。
3. 选择匹配数据源，点击`匹配元数据`。
4. 检查结果，修正匹配条目和启动程序，再点击`导入已匹配`。

![批量导入：Steam 库扫描结果及高级设置中的三种扫描模式](/images/addgame-bulk_20261002.png)

上图是扫描 Steam 库后的待处理列表，尚未匹配元数据。齿轮按钮用于打开`高级设置`；匹配后仍需逐项核对，不能只凭`已匹配`状态判断条目是否正确。

`待处理`、`未找到`、`错误`等条目可通过`导入为自定义`添加，之后在[游戏详情页](editgame.md)补充资料或用 ID 重新刮削。

### 扫描模式

- **可执行文件扫描（默认）：** 按扫描深度查找启动文件，以所在目录作为游戏条目。
- **一级目录导入：** 根目录下每个文件夹作为一个游戏。默认不查找启动文件，按需开启`扫描启动文件`。
- **Steam 导入：** 查找本机已安装的 Steam 游戏，匹配资料后导入。

## 云端收藏

可以导入 Bangumi、VNDB、Hikarinagi 的收藏及其游玩状态、评分和评价。

导入前，在设置中配置对应账号。

1. 在添加游戏弹窗中切换到`云端收藏`，选择来源并点击`读取收藏`。
2. 按名称或游玩状态筛选，检查勾选的条目，点击`导入所选`。
3. 查看结果；失败条目可通过`重试失败项`重试。

![云端收藏：读取 VNDB 收藏后勾选游戏并检查游玩状态](/images/addgame-cloud_20261001.png)

上图以 VNDB 为例。顶部可以搜索名称或来源 ID、筛选游玩状态，底部的`导入所选`按钮会显示当前勾选数量。

同一来源中已导入的游戏会被跳过；导入的游戏暂未关联本地文件，可选择`同步本地`，或在[启动设置](editgame.md#启动设置)中关联启动文件。

::: warning
 为防止重复导入相同游戏，请不要同时导入来自多个网站的收藏，**强烈建议**只导入一个网站的收藏
:::
