# 添加游戏

支持手动选择游戏启动文件和拖拽文件夹或启动文件两种方式添加游戏

## 单个添加

1. 打开游戏添加界面后，点击选择启动程序，选择游戏的启动文件

![选择启动文件](https://img0.huoshen80.top/i/2026/01/02/6957abeda5a8d.png)

2. 选择用于刮削数据的数据源，推荐使用 Mixed

3. 检查自动获取到的游戏名称是否正确，确认无误后点击确认

4. 查看刮削结果是否正确，如果部分数据源刮削有误，可以进入[游戏详情页编辑](editgame.md)修改数据源的相关部分

*确认弹窗*
![确认弹窗](/images/addgame_20260619_214122.png)

*选择弹窗*
![选择弹窗](/images/addgame_20260619_214314.png)

### 添加模式

Reina 添加游戏有多种模式，默认使用游戏名称进行 `Mixed` 搜索，此外还支持`单数据源`的游戏名称或者 ID 搜索以及`自定义`游戏

#### 自定义

想导入数据源可能没有的游戏时，可以选择自定义模式，需要前往[游戏详情页编辑](editgame.md)手动填写游戏的所有信息

#### 单源 ID 搜索

你可以在对应源的输入框中填入游戏 ID 进行准确搜索

如何获取 bgm、vndb、ymgal 和 kun 上的游戏 ID：
例如打开[Vndb](https://vndb.org/)，搜索对应游戏，进入游戏页面后，在网址栏中可以看到对应的 ID
![游戏ID位置](https://img0.huoshen80.top/i/2026/01/02/69579ad5ba25c.png)

## 拖拽文件夹或者启动文件

- 直接将游戏文件夹或者游戏启动文件拖拽到 Reina 内，松开鼠标后会自动进入添加流程

- 拖动多个游戏文件夹或者启动文件时，Reina 会自动进入批量导入流程

- 批量导入模式下再次拖拽游戏文件夹或者启动文件会被视为批量导入的补充操作

## 批量导入

1. 在游戏添加界面点击批量导入，选择一个包含所有游戏文件夹的目录，系统会自动扫描该文件夹下的所有的游戏并列出
2. 在弹窗右上角选择一个数据源（可选），高级设置中可选扫描模式和扫描深度，然后点击`匹配元数据`
3. 等待匹配完成后，可以手动修改匹配错误或者未找到的条目，也可以修改游戏的启动程序
4. 最后点击`导入已匹配`按钮，完成批量导入
![批量导入](/images/addgame_20260715_002627.png)

PS：`待处理`、`未找到`、`错误`等状态的游戏可以被导入为自定义游戏，自定义游戏只包含游戏名称和启动程序，其他信息需要前往[游戏详情页编辑](editgame.md)手动填写（也可以通过 id 刮削）

### 扫描模式

- 可执行文件扫描：默认模式，扫描选择目录下若干层级的可执行文件，一个可执行文件所在目录对应一个游戏
- 一级目录导入：扫描选择目录下所有文件夹各视为一个游戏
- Steam 导入：自动扫描本机的 Steam 游戏库

## 云端收藏

可以从 Bangumi、VNDB、Hikarinagi 等网站导入已收藏的游戏，导入后会自动匹配对应的游戏元数据

::: warning
 为防止重复导入相同游戏，请不要同时导入来自多个网站的收藏，**强烈建议**只导入一个网站的收藏
:::
