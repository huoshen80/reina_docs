# 数据备份与恢复

数据库保存游戏资料、收藏夹和游玩记录，自定义封面单独备份。操作入口位于`设置 → 路径与备份 → 数据备份与恢复`。

## 手动备份

1. 点击`备份数据库`，生成 `.db` 文件。
2. 点击`备份自定义封面`，生成包含 `covers` 文件夹的 `.7z` 压缩包。没有自定义封面时不会生成压缩包。
3. 点击`打开备份文件夹`查看结果。

默认备份目录：

- 安装版：`%AppData%\com.reinamanager.dev\data\backups`
- 便携版：`resources\data\backups`

可在`打开路径设置`中修改`数据库备份路径`，自定义封面备份也保存到该目录。

## 自动备份

在同一设置区域可开启`定时自动备份`或`退出时自动备份`，并选择是否同时备份自定义封面。

- 定时备份仅在应用运行或驻留托盘时执行。
- 退出备份在正常退出软件时执行，受设置的最小间隔限制。
- 保留数量按自动备份批次计算，清理时只删除旧的自动备份，手动备份会保留。

## 恢复数据

1. 点击`恢复数据库`，选择备份的 `.db` 文件。**恢复会覆盖当前数据库，不会合并游戏。**
2. 然后程序会先备份自定义封面，再尝试备份当前数据库，随后清空封面目录、恢复数据库并重启。
3. 如需恢复自定义封面，退出 ReinaManager，将与该数据库对应的封面备份包解压到数据目录：
   - 安装版：`%AppData%\com.reinamanager.dev`
   - 便携版：`ReinaManager.exe` 所在目录下的 `resources`
4. 确认解压后的结构为 `covers\game_游戏ID\...`，再启动 ReinaManager。

云端封面缓存会重新下载，自定义封面需按上述步骤恢复。

自定义封面备份失败会中止恢复；当前数据库备份失败只记录日志，仍会继续恢复。

## 搬迁到另一台电脑

在原电脑备份数据库和自定义封面，将备份文件复制到新电脑，再按恢复步骤操作。

游戏文件和游戏存档需另行搬迁。路径变化后，在[启动设置](editgame.md#启动设置)和[存档设置](savedata.md#存档备份相关设置)中修改路径。
