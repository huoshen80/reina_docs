# 游玩记录与统计

ReinaManager 会根据游戏启动和结束情况记录游玩次数与时长。打开任意游戏详情页，默认的`游戏统计`标签会展示这些数据；`统计页面`可以查看所有游戏的累计数据和图表。

有效计时时长不足一分钟时不会记录本次游玩，也不会触发游戏结束后的自动存档备份。

## 查看和补记单次游玩记录

点击统计图表右上角的列表图标，可以从图表切换到游玩记录列表。列表按日期分组，显示每次游玩的起止时间和时长。

需要补记遗漏记录时：

1. 切换到列表视图。
2. 点击`添加记录`。
3. 选择开始时间。
4. 填写游玩的小时数和分钟数。
5. 检查自动计算的结束时间，然后确认添加。

开始时间必须有效，总时长必须大于 0，结束时间不能晚于当前时间。

![添加游玩记录](/images/statistics_20260819_232247.png)

列表中的删除按钮用于移除错误记录。删除会影响累计次数、总时长以及图表结果，操作前请核对日期和时段。

## 选择计时方式

前往`设置 → 系统 → 游戏计时模式`可以选择：

- **真实游戏时间（默认）：** 只计算游戏窗口位于前台的时间，切换到其他窗口时暂停计时。
- **游戏启动时间：** 计算从启动到退出的完整时长，不区分前台或后台。

计时模式的修改只对之后启动的游戏生效，不会重算已有记录。
