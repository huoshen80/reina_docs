# 游玩记录与统计

ReinaManager 会根据游戏启动和结束情况记录游玩次数与时长。打开任意游戏详情页，默认的`游戏统计`标签会展示这些数据；`统计页面`可以查看所选时间范围内的全库数据和图表。

有效计时时长不足一分钟时不会记录本次游玩，也不会触发游戏结束后的自动存档备份。

## 查看单个游戏统计

在游戏详情页的`游戏统计`标签中，可以查看累计游戏次数、今日游戏时长、累计总时长和存档备份数。图表右上角的`7D`、`30D`、`M`、`1Y`、`ALL`按钮用于切换显示范围。

![游戏统计：累计次数、总时长和游玩时长图表](/images/statistics-game_20261001.png)

## 查看全库统计

点击左侧导航的`统计`，通过顶部的`周`、`月`、`年`选择时间范围：`周`显示最近 7 天，`月`显示最近 30 天，`年`显示最近 12 个月。也可以点击`自定义`，在日历中依次选择开始日期和结束日期，再点击`应用`；结束日期不能晚于今天。

页面会显示该范围内的游玩时长、游玩游戏数、通关游戏数、新增游戏数、活跃天数和活跃日均时长，下方提供时长排行、总游玩时长趋势以及游玩时段和星期分布。

![统计页面：按年查看全库指标、游玩时长排行和趋势](/images/statistics-overview_20261001.png)

## 查看和补记单次游玩记录

点击统计图表右上角的列表图标，可以从图表切换到游玩记录列表。列表按日期分组，显示每次游玩的起止时间和时长。

![游玩记录列表：按日期显示起止时间和计时时长，右上角可添加记录](/images/statistics-records_20261001.png)

需要补记遗漏记录时：

1. 切换到列表视图。
2. 点击`添加记录`。
3. 选择开始时间。
4. 填写游玩的小时数和分钟数。
5. 检查自动计算的结束时间，然后确认添加。

开始时间必须有效，总时长必须大于 0，结束时间不能晚于当前时间。

![添加游玩记录](/images/statistics_20260819_232247.png)

列表中的删除按钮用于移除错误记录。删除会影响累计次数、总时长以及图表结果，操作前请核对日期和时段。

## 选择计时方式

前往`设置 → 系统 → 游戏计时模式`可以选择：

- **真实游戏时间（默认）：** 只计算游戏窗口位于前台的时间，切换到其他窗口时暂停计时。
- **游戏启动时间：** 计算从启动到退出的完整时长，不区分前台或后台。

![游戏计时模式：真实游戏时间与游戏启动时间](/images/statistics-timing_20261001.png)

计时模式的修改只对之后启动的游戏生效，不会重算已有记录。
