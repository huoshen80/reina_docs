# 编辑游戏资料

如果你发现游戏资料有误，或者想要自定义游戏的封面、名称、Tag、开发商等元数据，可以通过编辑游戏资料来实现，在这里你还可以使用游戏 ID 重新刮削游戏资料

## 数据源编辑与更新

名称搜索：
![数据源编辑与更新-名称搜索](/images/editgame-source-search_20261002.png)
手动 ID：
![数据源编辑与更新-手动 ID](/images/editgame-source-ids_20261002.png)

先在`编辑`标签中展开`数据源编辑与更新`。Mixed 模式只显示已启用来源的 ID 输入框，参与来源可在`设置 → 数据源 → Mixed 搜索源`中调整。

### 切换显示源
使用已保存的数据源资料进行切换展示，不会重新获取数据。需要重新刮削时，使用名称搜索或手动 ID 更新。

### 名称搜索

此功能同单个添加游戏的流程，搜索框可以用回车触发搜索（单源也可以直接输入 ID 来搜索）

### 手动 ID

填写或修改对应来源的 ID，点击`从数据源更新数据`，核对预览后确认更新。Mixed 模式下，填写多个 ID 时会分别按这些 ID 获取资料。

若删除某个 ID 后只剩一个，Reina 会尝试补全其它已启用来源，刚删除的来源也可能重新匹配回来。想持续排除某个来源，应在 Mixed 搜索源设置中停用它。

### 使用单一 ID 重新进行 Mixed 刮削

数据源为 Mixed 时，手动 ID 模式下只填一个 ID，Reina 会先获取该条目的名称，再尝试匹配其它已启用来源。补全结果可能缺失或匹配错误，确认更新前请核对条目。

## 游戏资料编辑

在编辑 Tab，你可以选择或自定义游戏的名称、封面、开发商、Tag 等元数据，修改后记得点击右上角的`保存游戏资料`按钮

自定义资料优先于数据源资料。

![游戏资料编辑](/images/editgame-info_20261002.png)

其中游戏名称、开发商、封面、简介都可以直接选择：

![选择显示名称](/images/editgame_20260827_122149.png)

### 选择图片

封面可以选择本地图片，也可以选择从剪贴板导入，还可以选择数据源封面

![选择展示封面](/images/editgame_20260827_122642.png)

## 启动设置

一般直接使用`可执行文件`输入框右边的选择按钮

![启动设置](/images/editgame_20260827_123315.png)

Steam 游戏切换启动方式为`Steam`，从 Steam 库选择对应启动项，再点击`保存启动设置`。

## 评价与云端推送

打开游戏详情页的`评价`标签，填写评分和评价，点击`保存本地评价`。评分支持 1–10 分及一位小数，填 0 可清空评分。

需要同步到网站时，在`云端推送`中勾选目标站点，点击`推送`。游戏需绑定该站点的 ID，并已登录对应账号；VNDB Token 还需 `listwrite` 权限。

推送使用当前表单内容覆盖所选站点的评分和评价；推送到 Hikarinagi 时，还可选择是否推送游戏时长，并调整小时和分钟。

![评价标签：本地评分、评价及 BGM、VNDB、Hikarinagi 云端推送设置](/images/editgame-review_20261001.png)

上半部分用于填写和保存本地评价，下半部分用于选择推送站点。站点未登录、游戏未绑定对应 ID 或 VNDB Token 缺少 `listwrite` 权限时，其选项会显示为灰色；`保存本地评价`在表单有改动时可用。
