# 数据源与元数据展示

在`设置 → 数据源`中，可以配置元数据获取和显示方式。获取或补全会保存来源元数据；调整显示顺序只改变展示，无需重新获取元数据。

## Mixed 搜索源

Mixed 将多个来源的元数据保存在同一个游戏中。可在`Mixed 搜索源`中启用 2–4 个来源，用于 Mixed 搜索、按 ID 获取和关联增强。

名称搜索后可核对并勾选各来源的候选；按 ID 获取时，只请求已启用且填写了 ID 的来源。具体操作见[添加游戏](addgame.md)和[编辑游戏资料](editgame.md#数据源编辑与更新)。

## 单源自动增强

在`单源自动增强`中，可以分别开启 Kungal、Hikarinagi 自动扩展为 Mixed。获取该单源元数据时，会按条目提供的关联 ID 额外获取 Mixed 中已启用的其它来源元数据。单个添加、批量匹配和对应来源的云端收藏导入均可使用。

关闭增强后，仍可保存已启用来源的关联 ID，但不会自动获取其完整元数据。

![单源自动增强：分别控制 Kungal 和 Hikarinagi 是否获取关联来源元数据](/images/settings-source-expansion_20261106.png)

## 补全关联元数据

用于已入库，含 Kungal、Hikarinagi 来源及缺部分元数据的游戏，可使用该功能补全元数据。

1. 展开`实验性功能`，点击`检查可补全游戏`。
2. 勾选游戏，点击`获取元数据`。
3. 查看结果，点击`补全所选`保存；失败项可再次获取。

![补全关联元数据：先获取元数据，再确认保存](/images/settings-library-enrichment_20261106.png)

补全沿用 Mixed 来源设置及账号权限，不需要开启单源自动增强。已有元数据、自定义内容和启动设置会保留；关联身份冲突的条目会标注并跳过，不会自动合并游戏。关闭弹窗后，未保存的获取结果不会保留。

## 游戏元数据显示

点击`游戏元数据显示 → 打开游戏元数据显示设置`，拖动调整 Mixed 游戏的名称、简介和开发商来源顺序，再点击`保存`。越靠上越优先，缺少元数据时使用下一来源，对已有和新增的 Mixed 游戏均生效。

开启`原名优先`后，优先显示原名，缺失时使用中文名；关闭时沿用界面语言规则。单游戏的自定义内容始终优先，修改方式见[游戏资料编辑](editgame.md#游戏资料编辑)。

![游戏元数据显示：原名优先与各字段的来源顺序](/images/settings-metadata-display_20261106.png)
