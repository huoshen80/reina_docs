# 便携模式

## 便携模式的启用条件

当 `ReinaManager.exe` 所在目录下存在 `resources/data` 文件夹时，Reina 将启用便携模式。

## 便携模式的特点

没有自定义游戏存档备份根目录、数据库备份根目录时，便携模式默认文件存放位置如下：

``` shell
resources/
├── backups/            # 游戏存档备份文件夹
├── covers/             # 游戏封面文件夹
└── data/               # 数据库文件夹
    └── backups/        # 数据库备份文件夹  
```

`resources` 是便携版的用户数据根目录，数据库实际保存在 `resources/data/reina_manager.db`。

## 从安装版切换到便携版

如果想要切换到便携模式，可以按照以下步骤操作：

移动 `%AppData%\com.reinamanager.dev` 文件夹下 `covers` 和 `data` 文件夹（不动其它文件）到软件安装目录的 `resources` 文件夹下，`resources` 一般需要手动创建。

## 关于便携版的更新

- 官方便携版更新时，直接下载新版本的便携包解压后**彻底覆盖**原有的软件目录即可。

- 从安装版切换到便携模式、且仍位于原安装目录的用户，可使用软件的自动更新。如果已移动到其它目录，请按上述便携包方式更新。
