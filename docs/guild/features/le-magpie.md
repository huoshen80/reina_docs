# 一键转区与自动放大

## 启用方式

在游戏详情页右上角**更多**按钮中
![转区与放大](/images/le-magpie_20260619_215102.png)

如果没有提前配置对应工具路径，开启开关时会弹出`工具联动`设置窗口。

对于 LE 来说选择 `LEProc.exe`，对于 Magpie 来说选择 `Magpie.exe`

也可前往`设置 → 工具联动 → 打开工具联动设置`配置路径。`新游戏默认启用`决定之后添加的游戏是否默认联动该工具；已有游戏仍可在详情页的`更多`菜单中单独调整。

![工具联动：LE、Magpie 路径和新游戏默认启用设置](/images/le-magpie-settings_20261002.png)

## Magpie 注意事项

请不要使用管理员运行 Magpie，否则会出现无法联动使用的问题，包括但不限于在 Magpie 的快捷方式属性-兼容性中勾选`以管理员身份运行此程序`，以及在 Magpie 的设置中打开`始终以管理员身份运行`
