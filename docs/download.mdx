# 下载 ReinaManager

选择适合你设备的版本，点击下载即可获取安装包。

## 下载安装

<Download />

大多数 Windows 用户可选择 x64 安装版，下载后双击 `setup.exe` 文件，按照提示完成安装。MSI 安装包也可在上方切换下载。ReinaManager 不支持 Windows 7。

## 其他下载选项

更多下载文件请前往 [GitHub Releases](https://github.com/huoshen80/ReinaManager/releases/latest)。便携版的详细介绍见[便携模式](./guild/features/portable)。

Linux 版本由 [@wind-mask](https://github.com/wind-mask/ReinaManager) 维护。Arch Linux 用户也可以通过 AUR 安装 [reinamanager-bin](https://aur.archlinux.org/packages/reinamanager-bin)，该包由 [ycna](https://aur.archlinux.org/account/ycna) 维护。

下载完成后，可以继续阅读[快速开始](./guild/start/quick-start)。
